How we started?

I want to create a new BPMN model that fullfil these requirements so that I can publish in workspace:

  • 1. Conforms BPMN 2.0 syntax
  • 2. ACCURATELY represents as-is or to-be process that is presented in various formats and sources (SPOC, wiki, image, table, report, meeting transcript, process analysis)
  • 3. COMPLIANT: Meets the Signavio workspace standards set for BPMN modeling.
  • 4. STANDARDIZED with the existing processes and dictionary

01 — User Problem

1. User problem

The first model is still too much work for teams that already know the process.

Our users deal with stakeholders who often know the process, but their inputs arrive as notes, screenshots, tables, or documents — not clean BPMN. Process knowledge is scattered across tools and in different formats. The feature should remove the blank-canvas step and get them to a model they can review, correct, and share without need for BPMN expertise.

Blank-canvas tax

Teams spend time translating before they can discuss and improve the actual process.

Expertise barrier

Business users need an easier first step without becoming BPMN experts.

Uncompliant repository

Compliance and standardization relies on modeler's expertise or choice.

02 — Outcomes

2. Outcomes

The feature is successful when customers reach a trusted, editable BPMN model faster.

For users

Create a first BPMN draft from the material they already have, then review and modify without BPMN expertise instead of starting from blank. BPMN compliance, dictionary linking, and documentation attributes make the model useful in real workspaces.

For the business

Democratize modeling so more business users can contribute to standard process work.

For trust

Need for trust is observed to be higher with AI products. Privacy, personal-data guidance, cross-border transfer, and verification need to be visible in the experience.

03 — Use learnings to decide

3. What we've learned so far

The next iteration should respond to how teams actually try the feature.

Modeling a new process starts with blank canvas, best practice or an existing model as a reference

Modifying/duplicating old diagram or best practices require expert knowledge as well hindering democratization of modeling.

Our differentiator is workspace context, best practices and governance

Standardization and compliance is most time-consuming part after draft generation.

Adoption of AI needs a safe first step when activation is cumbersome

Labs access and feedback sessions let customers try the capability while we learn.

AI should ask for clarification instead of silently filling gaps

Most companies have built their own AI preparation layer before our tool.

For some mature users, creating new diagrams is no longer the primary use case.
